Investigating Netflix Movies

This repository contains an analysis of Netflix movies dataset, exploring various aspects such as movie ratings, genres, release years, and other characteristics to draw insights and patterns.

Project Overview

The project focuses on investigating a dataset containing information about Netflix movies, with the goal of identifying trends and key insights related to:

Movie genres and their popularity over time.
Ratings distribution and patterns in relation to release years.
Correlation between movie length, ratings, and genres.
Visualization of key data insights.
The analysis includes data cleaning, exploration, and the use of various statistical methods and visualization tools to interpret the data.

Key Features

Data Preprocessing: Cleaning and organizing the raw dataset to make it ready for analysis.
Exploratory Data Analysis (EDA): Investigating the relationships and trends between various movie features like genre, rating, and release year.
Visualizations: Generating visual plots such as histograms, scatter plots, and bar charts to illustrate the findings.
Insights: Extracting and summarizing the main conclusions from the data analysis.
Files

netflix_movies.csv: The original dataset containing information about Netflix movies.
movie_analysis.ipynb: The Jupyter notebook where the analysis is performed, including data cleaning, exploration, and visualizations.
README.md: Documentation for the repository, explaining the project and analysis steps.
